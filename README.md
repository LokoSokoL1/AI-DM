# DungeonMind

A local AI Dungeon Master for Dungeons & Dragons 5e.

## Goals

- Local LLM powered DM
- D&D 5e rules integration
- Adventure and rulebook retrieval
- Persistent characters and campaigns
- Foundry VTT integration
- Voice interaction
